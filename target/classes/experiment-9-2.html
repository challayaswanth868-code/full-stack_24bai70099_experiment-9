What is Continuous Integration?

CI ENABLED

Continuous Integration (CI) is a development practice where code changes are integrated into a shared repository frequently. Each change can trigger automated build and test stages to identify problems early.

  1. Develop features and commit code to Git.
  2. GitHub Actions checks out the latest repository code.
  3. Maven runs unit tests and integration/contract tests.
  4. A successful build is ready for the deployment pipeline.
  5. Test reports and build artifacts can be published.

Docker

Containerization reference

Example Dockerfile

For a Spring Boot application packaged as a JAR:

FROM eclipse-temurin:17-jre WORKDIR /app COPY target/*.jar app.jar EXPOSE 8080 ENTRYPOINT ["java", "-jar", "app.jar"]

Save as Dockerfile in the project root. This example requires a JAR to have been built first.

Open in VS Code
