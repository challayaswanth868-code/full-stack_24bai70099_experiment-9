What is Continuous Integration?

Continuous Integration (CI) is a development practice where code changes are integrated into a shared repository frequently. Each change can trigger an automated build and test process, helping teams find issues early.

  1. Develop features and commit code to Git.
  2. GitHub Actions checks out the latest repository code.
  3. Maven runs unit and integration tests.
  4. A successful build is ready for the next pipeline stage.
  5. Test reports and build artifacts can be published.

How to Run

Experiment 9.1 instructions

Start the Spring Boot application

  1. Open the project folder in VS Code.
  2. Open the terminal at the project root.
  3. Run mvn spring-boot:run.
  4. Open http://localhost:8080 in your browser.
  5. Use Dashboard, Test Center, and API Explorer from the left sidebar.

Run automated tests

mvn clean test mvn package

The dashboard's demo button simulates stage activity. Use Maven to execute actual Java tests.
